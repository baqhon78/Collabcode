# ⚡ CollabCode – Совместная онлайн-песочница для веб-разработки

**Тема дипломного проекта:** «Разработка веб-приложения для написания и совместного редактирования фронтенд-кода в реальном времени»

Веб-приложение для совместного редактирования HTML, CSS и JavaScript кода в реальном времени. Аналог CodePen с возможностью пригласить друга, вместе писать код и видеть изменения мгновенно.

## 🚀 Основные возможности

- ✍️ **Monaco Editor** – редактор кода как в VS Code (подсветка синтаксиса, автодополнение)
- 👥 **Совместное редактирование** – изменения отображаются у всех участников в реальном времени
- 💬 **Встроенный чат** – общение внутри редактора
- 👁️ **Превью результата** – мгновенный просмотр HTML/CSS/JS кода
- 📱 **Эмуляция мобильных устройств** – проверка адаптивности
- 🎨 **Шаблоны проектов** – быстрый старт с готовыми примерами
- 🔗 **Приглашение по ссылке** – подключение к комнате по ID
- ☁️ **Сохранение в облаке** – автоматическое сохранение в MongoDB
- 📦 **Экспорт в ZIP** – скачивание проекта одним архивом
- 🌓 **Тёмная/светлая тема** – настройка внешнего вида редактора

## 🛠️ Используемые технологии

| Компонент          | Технологии                          |
|--------------------|-------------------------------------|
| **Frontend**       | HTML5, CSS3, JavaScript (ES6+)      |
| **Редактор кода**  | Monaco Editor                       |
| **Backend**        | Node.js, Express                    |
| **Реальное время** | WebSocket (ws)                      |
| **База данных**    | MongoDB (Mongoose)                  |
| **Аутентификация** | JWT + bcrypt                        |

## ⚙️ Установка и запуск

### Требования
- Node.js версии 16 или выше
- MongoDB (локально или Atlas)

### Клонирование
```bash
git clone https://github.com/your-username/collabcode.git
cd collabcode/server
```

Установка зависимостей:

npm install

Настройка переменных окружения

Создайте файл .env в папке server:

PORT=3000

MONGODB_URI=ваша_строка_подключения_к_mongodb

JWT_SECRET=ваш_секретный_ключ

Запуск:

npm run dev

Откройте браузер: http://localhost:3000
